# 조항 요약

## 형식
```
## <표준> <조항번호> <조항명>

**핵심 요구사항** (키워드 3~5개)
- 

**문서화 정보** 유지(문서) / 보유(기록) 구분
- 

**다른 표준과 비교** (14001 ↔ 45001 대응 조항)
- 

**시험 포인트**
- 자주 나오는 함정 1~2개
```

## 원칙
- 한국어, 키워드 중심
- 원문 그대로 옮기지 않고 요약
- `notes/<표준>/<조항번호>.md`로 저장
