# ISO 모범답안 작성

## 순서
1. 문제에서 묻는 것을 한 줄로 정리한다.
2. 관련 조항 번호를 찾는다. (복수 가능)
3. 아래 형식으로 답안을 쓴다.
4. `answers/<표준>/<주제>.md`로 저장한다.

## 답안 형식
```
### 문제
(문제 요약 1줄)

### 관련 조항
- ISO 14001 6.1.2 — 환경측면

### 모범답안
- 핵심 키워드 1: 설명 1줄
- 핵심 키워드 2: 설명 1줄

### 심사 포인트
- 심사원이 확인할 증거(기록·문서·인터뷰)

### 흔한 부적합 사례
- 1~2개
```

## 원칙
- 키워드 중심, 문장은 짧게
- 표준 원문 장문 인용 금지 — 자기 말로 요약
- 불확실한 조항은 "확인 필요" 표시
