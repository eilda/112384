# 비품 대장 정리

## 순서
1. 사용자가 준 기존 비품 파일을 작업 폴더로 복사한다. (원본은 수정하지 않는다)
2. 실행: `python tools/asset_ledger.py --from <기존파일> --out 비품대장_<YYYYMMDD>.xlsx`
   - 기존 파일이 없으면 `--from` 없이 실행해 빈 양식을 만든다.
3. 출력된 열 매칭 결과를 확인한다. 잘못 매칭된 열이 있으면 사용자에게 한 줄로 알린다.
4. 사용자가 말한 처리 구분(이전/매각/폐기/보류)·상태·신사옥 배치가 있으면 비품대장 시트에 채운다.
5. 요약 시트의 **미입력 건수**를 확인해, 처리 구분이 빠진 품목을 사용자에게 알려 준다.
6. 결과 파일을 사용자에게 보낸다.

## 원칙
- 품목을 임의로 지우거나 합치지 않는다. 중복 의심은 비고에 표시하고 알린다.
- 매각 대상은 구입가·구입일이 있어야 매각가 판단이 가능하므로, 빠졌으면 짚어 준다.
