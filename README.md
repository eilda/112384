# 112384

ISO 경영시스템(14001·45001·19011) 학습·교육 자료 저장소.
Claude 세션에 연결해 쓰도록 설정되어 있다.

## 구성
| 경로 | 역할 |
|---|---|
| `CLAUDE.md` | Claude가 항상 따르는 기본 지침 (한국어, 키워드 중심) |
| `.claude/skills/iso-model-answer/` | 워크숍 모범답안 작성 절차 |
| `.claude/skills/clause-summary/` | 조항별 요약 정리 절차 |
| `answers/` | 작성된 모범답안 |
| `notes/` | 조항 요약 노트 |

## 고도화하는 법
- 지침을 바꾸려면 `CLAUDE.md`를 수정한다.
- 반복 작업이 생기면 `.claude/skills/<이름>/SKILL.md`를 추가한다.
